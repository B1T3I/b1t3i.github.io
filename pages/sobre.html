Sobre o CS Legacy

Um projeto desenvolvido para apresentar o cenário competitivo do Counter-Strike 2 de forma visual, organizada e acessível.

O que é o CS Legacy?

O CS Legacy é um website focado no cenário competitivo de Counter-Strike 2, reunindo informações sobre equipes, jogadores e os principais torneios do jogo.

O objetivo é transformar dados e conceitos do competitivo em uma experiência visual clara, permitindo que tanto novos usuários quanto jogadores experientes entendam o cenário de forma simples.

Objetivo do projeto

O projeto foi desenvolvido com foco em aplicar conceitos fundamentais de desenvolvimento web, incluindo estruturação semântica com HTML, estilização com CSS e interatividade com JavaScript.

Além disso, busca demonstrar organização de conteúdo, consistência visual e construção de uma interface moderna inspirada em sites reais do cenário competitivo.

Tecnologias utilizadas

HTML5
CSS3
JavaScript
Responsividade 📱
DOM ⚙️

LEGACY

Evolução do projeto

Antes da versão atual, o CS Legacy começou como um projeto simples de estudo, com estrutura básica, layout inicial e menor preocupação com identidade visual.

Ao longo do desenvolvimento, o site passou por diversas mudanças, incluindo melhorias no design, organização do conteúdo e implementação de interatividade.
